# 01 — v0.1: dashboard, graph view, item detail, chat

## Context (why now)

Ships once `shek_ui_common_utility` v0.1.0 and `shek_brain` v0.1.0 exist. Delivers the first usable frontend: view what's in your brain, explore the graph, chat with `qwen2.5:3b`.

## Non-goals

- No ingest UI (workflows / MCP handle ingest).
- No admin (kind editor, schema editor) — v0.2.
- No mobile layout — desktop only.
- No PWA / offline caching.
- No auth beyond paste-your-token.

## Design

### Routes shipped in v0.1
- `/` — dashboard: recent items (top 20), engine `/health`, brain `/health`.
- `/graph` — full graph view backed by `GET /graph/view?focus=&depth=2`.
- `/items` — list + semantic search (`GET /search?strategy=hybrid`).
- `/items/$id` — detail: metadata, mindmap (mermaid render), neighborhood (depth=1 subgraph).
- `/chat` — stream chat with `POST /task/chat/stream` on `model_engine`.

Deferred to v0.2: `/kinds`, `/workflows`.

### Auth
Login screen at `/` when no token in localStorage: single input, "Paste your bearer token", validates via `GET /health` on both brain + engine. Success writes to localStorage. Route guard on all other routes.

### API layer
- `lib/api/brain.ts` — `getHealth`, `listItems`, `getItem`, `search`, `graphView`.
- `lib/api/model_engine.ts` — `getHealth`, `listTasks`, `chatStream` (returns AsyncIterator over deltas).
- All go through the `@shek/ui-common` `fetcher` (bearer injection).
- Query keys via `keys` factory.

### Graph
Wrapper `components/GraphView.tsx` around `react-force-graph-2d`. Props: `{ nodes, edges, focusId?, onFocus?, onNodeClick? }`. Zoom, pan, drag, click. Node coloring via Tailwind CSS variables.

### Chat
`components/ChatWindow.tsx` — messages array in local state, `useSSE` for streaming deltas, autoscroll, retry-on-error. No history persisted client-side yet; can be extended later to POST message logs back to brain.

## Verification

Manual end-to-end script (with `shek_brain` + `model_engine` + Ollama already up):

1. `make dev` — open `http://localhost:5173`.
2. Paste bearer token in login form. Success redirects to `/`.
3. Dashboard shows engine + brain health tiles (green).
4. `/items` search "attention" — results appear within 2 s.
5. Click an item → detail view shows mermaid mindmap rendered, neighborhood graph on the side.
6. `/graph` → force-graph animates in with all nodes; click a node → drawer with details.
7. `/chat` → send "hi" → tokens stream from `qwen2.5:3b`, no full-turn wait.
8. `docker build` produces a static image; `docker run -p 5173:80` serves it.

Codified in `tests/e2e/` with Playwright in v0.2 (skip for v0.1).

## Risks

- `react-force-graph-2d` size (~250 KB). Route-split via TanStack Router's lazy loading for `/graph`.
- SSE + Vite dev proxy can be finicky. Fallback: direct XHR streaming (fetch with a reader).
- Mermaid mindmap render is heavy. Lazy-load `mermaid` only on item detail route.
